# TeamVory brand files

*Your team, perfectly organized.*

The logo was redrawn as vector files (SVG) from `teamvory-brand-sheet.png`. SVGs stay sharp at any size. The text is converted to shapes, so the files look the same on any computer without the font installed.

## Logo files

| File | Use it for |
|---|---|
| `teamvory-logo.svg` | Website header on light backgrounds |
| `teamvory-logo-white.svg` | Website header or footer on navy/dark backgrounds |
| `teamvory-logo-tagline.svg` | Home page hero, documents, presentations (light background) |
| `teamvory-logo-tagline-white.svg` | Same, on dark backgrounds |
| `teamvory-icon.svg` | The symbol alone (two people forming a check mark) |
| `teamvory-app-icon.svg` | App icon and browser tab icon |

## PNG exports (`png/`)

| File | Use it for |
|---|---|
| `teamvory-app-icon-32.png`, `-48.png` | Browser tab icon (favicon) |
| `teamvory-app-icon-180.png` | iPhone home-screen icon |
| `teamvory-app-icon-192.png`, `-512.png` | Android home-screen and install icon |
| `teamvory-logo-1200.png`, `teamvory-logo-white-1200.png` | Emails and places that don't accept SVG |
| `teamvory-logo-tagline-1600.png`, `-white-1600.png` | Social media, documents |
| `teamvory-icon-512.png` | Social profile pictures |

## Colors

| Name | Hex | Use |
|---|---|---|
| Deep Navy | `#0B1F44` | Text, headers, dark backgrounds |
| Teal Accent | `#14B8A6` | Buttons, icons, highlights, the logo |
| Dark Teal | `#0F766E` | Links and small teal text on white (bright teal is too light to read at small sizes) |
| Soft Gray | `#E2E8F0` | Borders, dividers, quiet backgrounds |
| Mint Tint | `#E6FFFA` | Selected states, soft highlight panels |

## Fonts (free on Google Fonts)

- **Poppins SemiBold** for the logo and headings
- **DM Sans** for body text, forms and the app interface

## Rules

- Leave clear space around the logo at least as wide as the left head in the symbol.
- Don't stretch, recolor, or add shadows to the logo.
- On navy or photo backgrounds, use the `-white` versions.
- Below about 120 px wide, use the symbol or app icon instead of the full logo.
