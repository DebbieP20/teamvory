Notes

  1. Default week is entered once. Each day is Off, All day or Custom times, because shift times change by season.
  2. This week covers only this week and next week, because the owner schedules at most 2 weeks out. It starts as a copy of the default (grey). Changing a day only affects that week and shows a Changed tag with Reset.
  3. If the week is already published, the change still saves. The manager sees a conflict, and the shift stays until they fix it.
  4. Time off needs no approval. If it overlaps a published shift, Cara is told to post the shift as open or talk to the manager.
  5. The owner uses the same screen, but his default week starts as All day every day. He only marks his days off.

Decided

  1. One time range per day.
  2. Changes for this week and next week only. Time off can be any future date.

Notes

  1. Only this week and next week can be set up, to match how far ahead you schedule.
  2. Copy last week is the usual one-click start. Shifts are normally 12–5 and 5–9 every day (the Standard pattern).
  3. Rain in the forecast? Click 🌧 Slow on that day: 1 person per shift. You can then put yourself on half the day or the whole day on the Schedule page.

Events you add in your phone's calendar show up in TeamVory by themselves, so you only enter them once.

Notes

  1. Reminders: you choose the start day and how many days in a row. They go out each morning. Example: Wednesday + 2 days = Wednesday and Thursday.
  2. Only employees missing next week's availability get it. Having a default week counts as set. Day 2 only goes to whoever still hasn't done it.
  3. It's only a reminder. There's still no deadline, and the dashboard shows who's missing.
  4. Calendar sync is on hold until you talk with the client. If it goes ahead: it reads one calendar (e.g. “TeamVory events”) through its link once a day, whenever you open the Dashboard or Events, and when you tap Sync now. Personal appointments in other calendars are never read.
  5. Synced events show up in Events and on the dashboard with a From calendar tag. You still add the staffing shifts yourself, and the dashboard reminds you if an event has none.
  6. Changes go one way: edit or delete the event in your phone, and TeamVory updates on the next sync.
